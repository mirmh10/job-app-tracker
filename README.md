# Job Application Tracker

A small, single-page app for tracking job applications. Add, edit, and delete applications; filter by status; and see the newest applications first. Entries are saved in your browser's local storage, so they remain after a refresh on the same browser and device.

## Run it

Open [index.html](index.html) in a browser. No installation or server is required.

## Fields

Each application has an automatically assigned numeric ID, company, role, date applied, optional posting link, status (`Applied`, `Interview`, `Rejected`, or `Offer`), and optional notes. Company, role, date, and status are required. Deleting an entry asks for confirmation.
